# Part 10 · Coverage Checklist

[← Index](README.md) · Previous: [Part 9 · Future work](09-future-work.md)

> **What this is.** A map from **every path in the repository** to the section that explains it, plus an honest list of what is documented only lightly or not at all. It was generated by a script that walks `git ls-files -co --exclude-standard` (681 paths on 2026-10-08: tracked files plus the untracked work not yet committed) and assigns each path to a section by rule; **no path was left unmapped** (the script stops if one is). Folders that are git-ignored (`node_modules`, `.next`, `.next-prod`, `.runtime`, `.storage`, `services/ai-engine/.venv`, `debug-indeed/`, `debug-recruiter-posts/`) are build or runtime output and are not part of the source.

**Depth legend.** **Deep** = read function by function and explained in Part 4/5/6 with file and function names. **Read** = read and explained at module level. **Header** = file headers, signatures and call sites read, behaviour summarised; internals (selectors, UI glue) not traced line by line. **Template** = inherited from the starter template, listed so nothing is hidden, not part of the thesis. **Data** = fixtures, snapshots, assets.
